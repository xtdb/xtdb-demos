# XTDB demos

Runnable examples of [XTDB](https://xtdb.com).
Each demo includes its own setup instructions and Docker Compose configuration.

| Demo | What it shows |
| --- | --- |
| [Fraud detection](fraud-detection) | Point-in-time fraud features, historical training, and replaying a score after a late chargeback |
| [Manufacturing inspection](manufacturing-inspection) | Apply a historical calibration correction, flag released parts for review, and reproduce the original assessment |
| [Live manufacturing inspection](manufacturing-inspection-live) | A running production line with a guided calibration investigation, stock holds, and replay of original decisions |
| [Vision inspection and human review](manufacturing-vision-review) | Review simulated camera predictions, distinguish production quality from model accuracy, and reproduce earlier reports |
